# 📌 Address Book (C Project)

## 📖 Description

The Address Book project is a console-based application developed in C
that helps users manage contact information efficiently. It demonstrates
the use of core programming concepts such as structures, file handling,
and modular programming.

This project is ideal for beginners who want to understand how
real-world applications store and manipulate data.

------------------------------------------------------------------------

## 🎯 Objectives

-   To implement a real-world application using C
-   To understand file handling and data persistence
-   To practice modular programming using multiple files

------------------------------------------------------------------------

## 🚀 Features

-   ➕ Add new contacts (Name, Phone, Email)
-   🔍 Search contacts by name
-   ✏️ Edit existing contact details
-   ❌ Delete contacts
-   📋 Display all saved contacts
-   💾 Store data permanently using files

------------------------------------------------------------------------

## 🛠️ Technologies Used

-   C Programming Language
-   Standard I/O Library
-   File Handling (fopen, fread, fwrite, etc.)

------------------------------------------------------------------------

## 📂 Project Structure

    AddressBook/
    │── main.c          # Entry point of the program
    │── functions.c     # All logic implementations
    │── functions.h     # Function declarations
    │── data.txt        # Stored contact data
    │── README.md       # Project documentation
